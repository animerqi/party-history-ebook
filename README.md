# 党史系列 · 网页电子书

《思维实验室》党史系列（52 集）的**文字转写与阅读性整理稿**，编排成一本可离线阅读的网页电子书。

**在线阅读**：<https://animerqi.github.io/party-history-ebook/>

## 这本书是什么

把 52 集视频的音频（约 27.5 小时）转成文字、逐集润色，按**历史时期**编成一部书：

| 项目 | 数值 |
| --- | --- |
| 章节 | 52 章（序 + 8 部） |
| 小节 | 571 个 |
| 正文字数 | 约 56.5 万字 |
| 附原文对照 | 另含约 56 万字原始机器转写（每章底部可展开逐句查证） |
| 音频总时长 | 27.46 小时 |
| 预计阅读 | 约 23.5 小时 |

分部结构：

```
序 · 关于这个系列
第一部 · 星火            1921—1934
第二部 · 长征与落脚陕北   1934—1937
第三部 · 抗战            1937—1945
第四部 · 内战开局         1945—1947
第五部 · 经略东北         1946—1948
第六部 · 战略决战         1947—1949
第七部 · 建国            1949—1950
第八部 · 新中国初期       1949—1956
```

## 阅读功能

- 左侧分部目录，已读章节自动打勾
- 全文搜索（支持多关键词）
- **历史顺序 / 发布顺序**一键切换
- 夜间模式、字号无级调节
- 自动记住阅读进度、主题与字号
- 每章底部可展开「原始机器转写」，逐句查证润色是否偏离原意
- 每章附 B 站原片链接（BV 号）
- 键盘 `←` `→` 翻页、`/` 聚焦搜索
- 手机端目录抽屉、打印样式
- 书末附录：《术语勘误表》（113 类错字订正）+《转写说明》

整站是**单个 HTML 文件**（约 3.5 MB），无外部依赖，克隆下来双击也能离线看。

## 制作过程与质量校验

- **转写**：`faster-whisper` + `large-v3`，CUDA float16（RTX 50 系 Blackwell 必须用 float16，int8 会触发 `CUBLAS_STATUS_NOT_SUPPORTED`）。
  避开了 faster-whisper 批处理管道的一个坑——实测它会**整段吞掉语音**，改用普通逐段解码。
- **润色**：逐集整理，只做语言与结构处理，**不添加原文没有的事实**；发现原文史实存疑处不改正文，只做记录。
- **校验**：8 项自动检查全部通过——章节齐全、结构规范、字数保真 1.0072、
  **滑窗保真度 0 处整段丢失**、复读 0、广告残留 0、全书订正一致、jsdom 渲染与 29 项交互测试通过。
- 与 B 站官方 AI 字幕交叉验证（8 集）：4-gram Jaccard 平均 0.774，官方字幕内容覆盖率 0.891。

**如实说明的两类删减**（书中附录亦有说明）：① 品牌广告口播（仅 1 集有）；② 仅在视频语境成立的自我引用插叙（1 处）。除此之外未删除任何内容。
